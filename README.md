# Sally Launcher

Launcher Android untuk Minecraft Bedrock Edition (pemilik lisensi resmi), berbasis LeviLauncher (Apache-2.0) dengan tampilan dan nama Sally.

- Package: `com.sally.launcher` (namespace kode tetap `org.levimc.launcher` agar runtime, JNI, dan preloader tidak berubah)
- Tema: hijau zamrud MD3 (terang/gelap), tab Beranda · Versi · Konten · Pengaturan
- Firebase opsional: taruh `app/google-services.json` milikmu (package_name `com.sally.launcher`). Tanpa file itu build tetap jalan dan crash report tidak dikirim.

Lisensi asli (Apache-2.0) ada di `LICENSE`.
